DMFT Work Monitoring Portal, Ramgarh - working prototype
Working prototype submitted by Nevaeh Technology Pvt. Ltd.

HOW TO OPEN
1. Copy this folder to the laptop (or run it from the pen drive).
2. Double-click index.html. It opens in Google Chrome or Microsoft Edge.
3. No internet connection, installation or server is needed. All fonts, charts, maps and Excel export are bundled.

SIGNING IN (demo)
- Public Dashboard opens first and needs no login.
- Click "Officer Login", choose any of the 9 roles, keep the demo password Demo@2026,
  answer the security sum, click Continue, then type the 6-digit OTP shown on screen.
- Each role sees its own menu and jurisdiction (for example the Execution Department sees only its department's works,
  the Field team sees the Field App for Mandu block).

DEMO DATA
- All projects, firms, amounts, PAN/GSTIN and records are fictional sample data for demonstration.
- Changes made during the demo (new work requests, file movements, uploads, progress, imports) are saved in this browser.
- To start again, sign in and choose "Reset demo data" at the bottom of the left menu.

MAP
- The map uses schematic block boundaries drawn for demonstration, so it works offline.
  The layer button (top right of the map) can switch to OpenStreetMap when the laptop is online.

LANGUAGE AND ACCESSIBILITY
- English / Hindi switch, text size A- A A+, and high-contrast mode are in the top bar of every page.

Best viewed in the current version of Chrome or Edge at 1366x768 or above. The Field App also works on a phone-width window.
